=====================
Web Konvergo BOT
=====================

Integrate `Konvergo BOT JS library <https://www.npmjs.com/package/@konvergo-bot/js>`_ with the Odoo backend.

This module only loads the JS script into the backend webview assets.

**Table of contents**

.. contents::
   :local:

Configuration
=============

No configuration is necessary, as the JS script is loaded as soon as the module gets installed.

Usage
=====

To invoke a bot from the backend, follow the `library documentation <https://www.npmjs.com/package/@konvergo-bot/js>`_
